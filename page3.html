• ความรู้พื้นฐานเกี่ยวกับเว็บไซต์
  • ภาษา HTML และการสร้างโครงสร้างเว็บไซต์
  • การตกแต่งเว็บไซต์ด้วย CSS
  • การเพิ่มความสามารถด้วย JavaScript
  • การสร้างและเผยแพร่เว็บไซต์

การตกแต่งเว็บไซต์ด้วย CSS

CSS (Cascading Style Sheets) คือภาษาที่ใช้สำหรับตกแต่งเว็บไซต์ให้สวยงามและเป็นระเบียบ เช่น การกำหนดสี ตัวอักษร ขนาด ระยะห่าง พื้นหลัง และการจัดวางองค์ประกอบต่าง ๆ โดย CSS สามารถใช้ร่วมกับ HTML เพื่อกำหนดรูปแบบของหน้าเว็บไซต์ให้เหมาะสมและน่าสนใจมากขึ้น
