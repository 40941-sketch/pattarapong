• ความรู้พื้นฐานเกี่ยวกับเว็บไซต์
  • ภาษา HTML และการสร้างโครงสร้างเว็บไซต์
  • การตกแต่งเว็บไซต์ด้วย CSS
  • การเพิ่มความสามารถด้วย JavaScript
  • การสร้างและเผยแพร่เว็บไซต์

ความรู้เบื้องต้นและโครงสร้างอินเทอร์เน็ต

เว็บไซต์ (Website) คือกลุ่มของหน้าเว็บที่เชื่อมโยงกันและเผยแพร่บนอินเทอร์เน็ต ผู้ใช้งานสามารถเข้าถึงผ่านเว็บเบราว์เซอร์ เช่น Chrome, Safari หรือ Firefox โดยเว็บไซต์มีส่วนประกอบพื้นฐาน ได้แก่ Domain Name หรือชื่อโดเมน ซึ่งเป็นที่อยู่ของเว็บไซต์, Web Server คือระบบที่เก็บไฟล์และส่งข้อมูลให้ผู้เข้าชม, Web Browser คือโปรแกรมสำหรับเปิดเว็บไซต์, Web Page คือแต่ละหน้าภายในเว็บไซต์ และ URL คือที่อยู่เฉพาะของหน้าเว็บแต่ละหน้า ภาษาที่ใช้ในการสร้างเว็บไซต์ ได้แก่ HTML สำหรับกำหนดโครงสร้างและเนื้อหา CSS สำหรับตกแต่งเว็บไซต์ และ JavaScript สำหรับเพิ่มความสามารถในการโต้ตอบ ส่วน PHP, Python, Java และ Node.js มักใช้พัฒนาส่วน Backend ที่ทำงานบนเซิร์ฟเวอร์ เว็บไซต์ยังแบ่งเป็น Frontend ซึ่งเป็นส่วนที่ผู้ใช้มองเห็นและโต้ตอบ เช่น ปุ่ม เมนู และแบบฟอร์ม และ Backend ซึ่งทำงานเบื้องหลัง เช่น การประมวลผลข้อมูล การเข้าสู่ระบบ และการติดต่อฐานข้อมูล ฐานข้อมูล (Database) ใช้สำหรับจัดเก็บข้อมูลต่าง ๆ เช่น ข้อมูลสมาชิก สินค้า คำสั่งซื้อ บทความ และความคิดเห็น โดยมีระบบที่นิยมใช้ เช่น MySQL, PostgreSQL และ MongoDB นอกจากนี้ HTTPS คือการสื่อสารระหว่างผู้ใช้กับเว็บไซต์ที่มีการเข้ารหัส ช่วยเพิ่มความปลอดภัยในการส่งข้อมูล โดยสังเกตได้จาก https:// และสัญลักษณ์รูปกุญแจในเว็บเบราว์เซอร์
